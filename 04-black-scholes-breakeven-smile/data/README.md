# Data

* `etf_daily_log_returns.csv`: daily total-return log returns (adjusted close) for SPY, EEM, TLT, GLD, USO, URA and HYG, 2006-04 to 2026-11-20, from Yahoo Finance. It is the same file as project 01 (see `../../01-monte-carlo-calibration/src/fetch_data.py`).
* `vix_daily.csv`: CBOE VIX daily OHLC, 1990-01-02 to 2026-09-22, from https://github.com/datasets/finance-vix (data/vix-daily.csv), which mirrors CBOE's published history.

Market data belongs to its providers and is used here for research only.
